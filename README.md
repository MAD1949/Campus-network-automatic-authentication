# 校园网自动登录工具（Python + 系统托盘版）

基于 **Dr.COM 城市热点认证协议** 的校园网自动登录工具，支持图形界面配置、系统托盘常驻、开机自启、断线自动重连。

## 功能特性

- **图形界面配置**：认证地址、账号、密码、运营商均可自定义，保存为 `config.json`
- **系统托盘常驻**：程序启动后驻留托盘，关闭窗口自动最小化到托盘，不退出
  - 图标颜色：🟢 绿 = 在线　⚪ 灰 = 离线　🔴 红 = 登录失败（悬停图标查看详细状态）
  - **右键托盘图标**：配置窗口 / 立即登录 / 检查状态 / 开机自动登录 / 断线自动重连 / 打开日志文件 / 退出
- **开机自启**：写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，静默自动登录
- **断线自动重连**：每 60 秒检测在线状态，掉线自动重新登录（可在托盘菜单开关）
- **静默模式**：`--login` 参数启动时不显示窗口，仅托盘 + 右下角通知气泡

## 文件说明

| 文件 | 说明 |
|------|------|
| `校园网自动登录.py` | 主程序（Python 源码） |
| `校园网自动认证系统.exe` | PyInstaller 打包的单文件版（`dist/` 目录，无需 Python 环境） |
| `config.json` | 配置文件（首次保存后生成，与程序同目录） |
| `login.log` | 运行日志（与程序同目录） |

## 快速开始

### 方式一：直接运行 Python 脚本

```bash
# 安装依赖（仅需一次）
pip install pystray pillow

# 启动（图形界面 + 托盘）
python 校园网自动登录.py

# 静默模式（开机自启使用）
python 校园网自动登录.py --login
```

### 方式二：使用打包好的 exe（推荐）

直接双击 `dist\校园网自动认证系统.exe`，或将其复制到固定位置运行。首次运行会弹出配置窗口，填写后点「保存并登录」。

### 首次配置

1. 运行程序 → 配置窗口
2. 填写认证地址（默认 `http://172.16.0.66`）、账号、密码
3. 选择运营商（电信账号自动加 `@dx` 后缀，联通加 `@lt`）
4. 按需勾选「开机自动登录」「显示登录通知」
5. 点击「保存并登录」

之后启动程序会自动读取配置登录并驻留托盘；右键托盘图标可随时修改配置。

### 开机自启

- 配置窗口勾选「开机自动登录」保存，或托盘右键菜单勾选「开机自动登录」
- 原理：注册表 Run 项，登录 Windows 后以静默模式自动运行并认证
- 取消勾选即删除启动项

## 配置说明（config.json）

```json
{
    "portalHost": "http://172.16.0.66",   // 认证地址
    "userId": "2024210674",               // 账号（含运营商后缀）
    "password": "********",               // 密码（明文存储在本地）
    "ispType": 0,                         // 运营商：0本地 1移动 2联通 3电信
    "autoStart": true,                    // 开机自启
    "showNotify": true,                   // 登录结果通知气泡
    "autoRelogin": true                   // 断线自动重连
}
```

## 认证协议（Dr.COM 城市热点）

逆向自门户页面并实测验证：

- **状态查询**：`GET {portal}/drcom/chkstatus?callback=drN&jsVersion=4.X&v=N&lang=zh`，响应 JSONP 中 `"result":1` 表示在线
- **获取本机认证 IP**：门户首页内嵌 `v4ip='x.x.x.x'`（失败时以 TCP 连接本地地址兜底）
- **登录**：`POST {portal}/drcom/login`，表单：
  `DDDDD=账号 & upass=密码 & 0MKKey=123456 & R1=0 & R2= & R3=0 & R6=0 & para=00 & v4ip=本机IP & v6ip= & terminal_type=1 & lang=zh`
  - 成功：响应包含 `Dr.COMWebLoginID_3.htm`
  - 失败：响应包含 `Dr.COMWebLoginID_2.htm`（附 `msga` 错误信息）

## 自行打包 exe

```bash
pyinstaller -F -w -i 图标.ico -n 校园网自动认证系统 校园网自动登录.py
```

- `-F` 单文件　`-w` 无控制台窗口　`-n` 输出名称　`-i` 图标
- 打包后程序自动适配：配置与日志均读写 exe 同目录

## 常见问题

- **托盘图标不显示**：未安装 pystray，执行 `pip install pystray pillow`
- **开机没自动登录**：托盘菜单确认「开机自动登录」已勾选；任务管理器→启动 中查看启动项是否被禁用
- **登录失败**：查看 `login.log` 中的 `msga` 错误信息（常见：密码错误、账号欠费、已达在线终端上限）
- **想彻底退出**：托盘右键 →「退出」

## 适用环境

- Windows 10 / 11（桌面版，支持系统托盘）
- Python 3.8+（源码运行方式）
- 适用采用 Dr.COM 认证系统（`/drcom/login` 接口）的校园网
